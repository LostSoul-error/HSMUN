## 📖 About

**HSMUN (Hem Sheela Model United Nations)** is the flagship Model United Nations conference organized by **Hem Sheela Model School, Durgapur**.

This website serves as the official digital platform for the conference, providing delegates, executive board members, international press, and visitors with information regarding committees, secretariat, registrations, and conference updates.

The project focuses on delivering a modern, cinematic user experience through elegant animations, immersive visuals, and responsive design.

# 🚀 Getting Started

## Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/HSMUN-2026.git
```

## Navigate to the project

```bash
cd HSMUN-2026
```

## Install dependencies

```bash
npm install
```

## Start development server

```bash
npm run dev
```

---

# 📦 Production Build

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
